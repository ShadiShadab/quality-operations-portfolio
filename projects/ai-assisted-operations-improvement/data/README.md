# Data

Everything in `synthetic/` is **synthetic**. It was generated by `src/generate_data.py` (seed 20261118) and does not describe any real organisation, person or request. Budget codes, amounts, dates, sites and teams are invented.

Regenerate with `python src/generate_data.py`. The output is deterministic; a test checks this.

## requests.csv

| Column | Meaning |
|---|---|
| `request_id` | `REQ-0001`… in arrival order |
| `received_at` | Synthetic timestamp |
| `week` | 1–12; weeks 1–6 are the development split, 7–12 held-out |
| `channel` | `email` or `web_form` |
| `requester_team` | Fictional team name |
| `form_category` | Category picked in the web form (empty for email); deliberately wrong in about 20% of cases |
| `subject`, `body` | Request text |
| `true_category` | Ground-truth category, known by construction |
| `true_priority` | `P1` (safety), `P2` or `P3` |
| `style` | `clear`, `indirect` or `trap` |
| `multi_intent` | `1` if a second, unrelated request is appended |
| `contains_injection` | `1` if instruction-like text is appended |
| `sensitive` | `1` for HR and safety categories |
| `missing_fields` | Required fields the request does not contain, separated by `;` |

## events.csv

| Column | Meaning |
|---|---|
| `request_id` | Links to requests.csv |
| `event` | `received`, `first_touch`, `handoff`, `info_requested`, `info_received`, `resolved` |
| `timestamp` | Synthetic timestamp |

The event log is simulated from the assumptions in [docs/03-baseline-and-data.md](../docs/03-baseline-and-data.md).
