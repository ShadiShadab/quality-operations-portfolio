## Limits of these figures

- **Missing-information recall is partly circular.** The check looks for the exact formats the generator uses, so it cannot miss a field the generator left out. The precision figure is more informative: when a requester writes a field informally, the check asks for information that was already given.
- **The missing-information check is scored with the true category.** In use it would run on the category the rules or a coordinator chose, so routing errors would add further mistakes.
- **Policy B's result depends on an assumption.** In the generator, a wrong web-form category is chosen at random, independently of the message text. Real requesters may choose the wrong category for the same reason the rules do (misleading keywords). Errors would then agree, and Policy B would misroute more often than shown here.
- **Sensitive-request protection is partly circular.** The protected-hint list was written with knowledge of the generator's vocabulary. Real messages will contain phrasing the list does not cover.
