# 8. Implementation roadmap

> **Status: proposed.** No phase has been carried out.

| Phase | Scope | AI? | Exit criterion |
|---|---|---|---|
| 0. Real baseline | Export 2–4 weeks of requests; label a sample twice; time triage effort | No | Baseline measures and human agreement rate known |
| 1. Process fixes | Required-field form, one request per submission, protected lane with notification, weekly dashboard | No | Form live; protected lane tested with safety focal point |
| 2. Rules (Policy B) | Rules plus form agreement for AUTO; completeness check; "not mine" button | No | Spot-check shows misroutes at or below the agreed level |
| 3. AI shadow pilot | AI suggestions for REVIEW logged, not shown | Yes | Accepted-but-wrong estimate and zero sensitive requests on the AI path |
| 4. AI assisted pilot | Suggestions shown in REVIEW, coordinator confirms | Yes | Pilot thresholds met |
| 5. Decide | Adopt, adjust or stop | — | Decision recorded with the measured results |

Phases 0–2 deliver most of the expected benefit and can be carried out with existing tools. Phases 3–5 should start only if Phase 2 leaves a meaningful amount of REVIEW-lane work.
